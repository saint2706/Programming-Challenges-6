# Programming Challenges 6

The sixth iteration of my programming challenges repository: 150 standalone challenges in five
categories, each its own small project with a README that covers the problem, the method and the
results. This site lists the challenges that are implemented.

| Category                 | Focus                                                                                 |
| ------------------------ | ------------------------------------------------------------------------------------- |
| Practical Software       | Real tools you'd actually install and use day to day                                  |
| Algorithmic Challenges   | Classic and advanced CS problems, data structures, and complexity trade-offs          |
| Web Development Showcase | Portfolio-worthy, interaction-heavy frontend and full-stack builds                    |
| Data Analytics           | Wrangling, exploring, visualizing, and reporting on data — no predictive modeling     |
| Practical ML             | Applied, production-flavored machine learning: serving, monitoring, evaluation, MLOps |

Every README starts with the category, a difficulty (B beginner, I intermediate, A advanced,
X expert) and a status, then the data, the method and the results.

The source, the full progress tracker and the CI status are on
[GitHub](https://github.com/saint2706/Programming-Challenges-6).
