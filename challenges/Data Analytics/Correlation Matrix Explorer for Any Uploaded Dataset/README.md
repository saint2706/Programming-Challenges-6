# Correlation Matrix Explorer for Any Uploaded Dataset

**Category:** Data Analytics
**Difficulty:** B

**Status:** Implemented (Python)

Hand it any CSV and get one self-contained, interactive HTML heatmap of the
correlations between its numeric columns, with significance flags that
account for testing many pairs at once.

## What it does

- **Any CSV.** Sniffs the delimiter (comma, semicolon, tab, pipe) and
  encoding (`utf-8`, then `latin-1`), treats `NA`/`N/A`/`NaN`/`null`/empty
  as missing, and auto-selects the numeric columns. Everything it drops is
  listed in the report with a reason: not numeric, constant (zero
  variance), or fewer than 3 non-null values.
- **Pearson and Spearman**, both computed with `scipy.stats`, switchable
  in the report with a button. Pearson measures linear association;
  Spearman measures monotonic association, so it catches relationships
  Pearson understates.
- **Pairwise deletion.** A missing value only removes the rows it sits in
  for the pairs it belongs to, not the whole dataset. Every cell reports
  its own `n` on hover.
- **Multiple-comparison-aware significance.** With 12 columns there are 66
  pairs; at p < 0.05 you'd expect ~3 false positives from pure noise. Cells
  flagged `*` pass a Benjamini-Hochberg correction (FDR 0.05 by default,
  `--alpha` to change) applied across the unique pairs of each method.
- **Hover** shows r, p, n, and the significance flag. Undefined cells
  (too few overlapping rows, or a column that becomes constant after
  pairwise deletion) show `n/a` instead of a misleading number.
- **One HTML file, no internet required to view it.** Plotly's JS bundle
  is embedded inline. A table lists every significant pair.

## Design notes

Uses **polars** for loading and column selection, **scipy** for the
statistics (so p-values are the reference implementation's, not a
hand-rolled approximation), and **Plotly** for the heatmap.

**Why BH and not Bonferroni:** Bonferroni controls the chance of *any*
false positive and gets very conservative as the column count grows.
Benjamini-Hochberg controls the *fraction* of flagged pairs that are false
discoveries, which is the more useful guarantee when exploring a wide
dataset. The step-up rule is implemented directly (about ten lines,
`benjamini_hochberg`) and tested against a textbook example.

**Why it's per method:** the Pearson and Spearman p-values are different
families of tests, so each matrix gets its own correction.

**Column names are untrusted input.** Plotly renders tick and hover text
as HTML, so every column name (and the page title, taken from the file
name) goes through `html.escape` before it reaches the figure or the page.
There is a test with `<script>` and `<img onerror>` column names.

`sample_data/health_survey.csv` (300 rows, generated by `make_sample.py`
with seed 42) has known structure: age ↔ income, exercise ↔ resting heart
rate (negative), a pure-noise column, a constant column, a text column,
missing values, and a `dose_mg` → `response` pair that is exponential:
Pearson r ≈ 0.76 but Spearman ρ ≈ 0.99.

## Run it

```bash
cd "challenges/Data Analytics/Correlation Matrix Explorer for Any Uploaded Dataset"

uv run python correlation_explorer.py sample_data/health_survey.csv -o report.html
# then open report.html in a browser

# options
uv run python correlation_explorer.py data.csv --sep ";" --alpha 0.01 -o out.html
```

## Test it

```bash
uv run pytest -q
```

Tests cross-check every cell against `scipy.stats` and cover pairwise
deletion, degenerate columns, BH, the sample dataset's known
relationships, delimiter/encoding handling, HTML escaping, and the CLI.
