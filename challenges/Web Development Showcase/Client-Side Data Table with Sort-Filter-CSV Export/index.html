Client-side data table

Sort, filter and export a large dataset entirely in the browser. Only the rows on screen exist in the DOM.

Click a header to sort (asc, desc, off); Shift+click adds a secondary sort. Numeric and date filters take >50000, <=100, =42 or 40000..60000. With the grid focused: arrow keys, PgUp/PgDn, Home/End (with Ctrl for the first/last cell).
