Theme Customizer Playground

A theme is a handful of typed CSS custom properties. Everything else (the palette, surfaces, labels, type scale) is computed in CSS from them.

This browser cannot compute OKLCH relative colours or light-dark() in CSS, so the colours are computed in JavaScript instead. The result is the same, to within one colour step.

Import a theme

A CSS file with the inputs, or a design-tokens JSON file. Only the values of known inputs are read; anything else in the file is ignored, and a file with a bad value changes nothing.
