Animated SVG Icon Library

A data/analytics-themed icon set — 19 hand-coded, license-clean SVGs. Hover (or tab to and focus) any icon to trigger its animation. Most use CSS; a handful use native SMIL (<animate>/<animateTransform>/<animateMotion>) instead — each panel is labeled with which technique it uses. Expand “View source” on any card to copy its raw, self-contained markup.
