How matching works

A query matches when its letters appear in the title in order, not necessarily next to each other. What makes it useful is the ranking.

Subsequence matching

plt matches Palette: a p, then an l, then a t, in that order. ptl does not, because no l follows a t. Order matters, adjacency does not.

Bonuses

Every matched character scores a base amount, plus a bonus for where it sits. The best alignment of the query across the title wins, found with a small dynamic program rather than a left-to-right scan.

Word starts

A character at the start of a word, after a space, slash, dash or dot, scores most. That is why gs finds Getting started ahead of a title that merely contains a g and an s.

Camel case and digits

A capital after a lower-case letter, and the first digit of a number, count as word starts too, so usa finds useAuthSession.

Runs

Characters that follow each other inherit the bonus of the first one in the run. Typing the first few letters of a word scores like a word start for each letter.

Gaps

Skipping characters between two matches costs a little for the first skipped character and a little less for each further one, so a tight match beats a scattered one. The first query character counts double, which favours matches that begin where the title does.

Multiple words

A query with spaces is several queries that must all match. match gaps finds the Gaps heading on this page: one word hits the title, the other hits the page it lives on. A match in the title counts in full, a match in a keyword or in the page name counts for less.

Case and diacritics

Matching ignores case and accents: cafe finds Café. Matched characters are reported as positions in the title, which the palette wraps in a styled span using text nodes, never by building HTML from the title.

Limits

Queries are cut to 32 characters per word and six words. Titles longer than 256 characters are matched with a cheaper left-to-right scan. The matcher does not forgive typos: mathcing finds nothing, because the letters are not in order.
