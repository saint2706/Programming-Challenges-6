Palette Notes

Notes on building a keyboard-first command palette for a static site, written on a static site that has one.

Try it

Press Ctrl K (⌘ K on a Mac) or / anywhere on this page, or use the Search button in the header. Type a few letters of anything: a page, a heading, a command. gs finds Getting started, ime finds the composition notes, theme switches colours.

Why a palette on a static site

A static site has no search server and usually no search box. A palette gives readers one place to jump to any page or section by typing a fragment of its name, and the same box can run small commands such as switching the theme or copying the link. The page index is built once, at build time, from the headings that already exist in the HTML.
