Getting started

Four steps from a folder of HTML pages to a working palette.

Install

The palette has no runtime dependencies. Copy src/ next to your pages and link the stylesheet and the script in each page's <head>. Vite bundles them; any bundler that understands ES modules and JSON imports will do.

npm install
npm run dev

Generate the index

The index is made by a script, not by hand. npm run index reads every .html file in the project root and records the page title, its description and every h2 and h3 that has an id. A heading without an id stops the build with a message naming the page, because there would be nothing to link to.

What an entry looks like

{ "id": "h:matching.html#gaps", "type": "heading",
  "title": "Gaps", "hint": "How matching works",
  "url": "matching.html#gaps" }

Pages may add <meta name="keywords"> to be found by words that are not in their title.

Wire up the trigger

Any element with data-palette-open opens the palette. Ship it with the hidden attribute: the script reveals it, so a visitor without JavaScript never sees a button that does nothing. A [data-palette-hint] inside it is filled with ⌘K or Ctrl K for the visitor's platform.

Add your own command

Commands live in src/actions.js. Each one is a search item plus a run function that receives the theme, recents, toast and window.

{
  id: 'a:top', type: 'action',
  title: 'Scroll to top', keywords: ['start'],
  run: ({ win }) => win.scrollTo({ top: 0 }),
}

Choosing a command closes the palette first, then runs it, so it acts on the page and not on the dialog.
