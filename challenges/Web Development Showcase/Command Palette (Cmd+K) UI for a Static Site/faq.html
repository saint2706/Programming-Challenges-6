FAQ

Does it work without JavaScript?

The site does: every page is plain HTML linked from the header menu, and the search button is not shown. Only the palette needs JavaScript.

Where are recent items stored?

In your browser's localStorage under palette:recent, the last five things you picked. If storage is blocked or holds something unexpected, the palette ignores it and keeps recents in memory for the life of the page. Clear recent items in the palette wipes them.

Can it search page text?

No. It searches titles, headings and keywords only. Searching body text is a different problem (stemming, snippets, an inverted index) and a tool such as Pagefind does it well.

Why not use a fuzzy-search library?

The matcher here is hand-written so that the ranking can be explained and tested. The project's benchmark compares it with Fuse.js and uFuzzy on ranking quality and speed.
