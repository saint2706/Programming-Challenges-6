Keyboard shortcuts

The palette is meant to be used without leaving the keyboard.

Opening

KeysDoes
Ctrl K / ⌘ KOpen from anywhere, even from a text field. Pressed again, it closes.
/Open, unless you are typing in a field.

Moving

KeysDoes
↓ ↑Next and previous result, wrapping at the ends.
Ctrl N Ctrl PThe same, for people who keep their hands on the home row. Ctrl J and Ctrl K are aliases.
Page Up Page DownFive results at a time.
Home EndFirst and last result while the box is empty; with text in it they move the caret as usual. Add Ctrl to move the list regardless.

Choosing

KeysDoes
EnterOpen the page or heading, or run the command.
Ctrl Enter / ⌘ Enter / Shift EnterOpen a page or heading in a new tab and keep the palette open.

Closing

Esc, a click on the dimmed area, or the Close button. Focus goes back to whatever had it before you opened the palette.

Platform notes

Browsers reserve a few shortcuts that a page cannot take over. On Windows and Linux, Chrome keeps Ctrl N for a new window, so use the arrow keys or Ctrl J there. On a Mac, Ctrl N is not reserved and works as written.
