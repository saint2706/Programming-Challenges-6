Accessibility notes

What the palette exposes to assistive technology, and the decisions behind it.

Combobox and listbox

The search field is an ARIA combobox that controls a listbox. Results are grouped (Recent, Actions, Pages, Headings) with role="group" and a label. Real focus stays in the field the whole time; the highlighted result is announced through aria-activedescendant and marked aria-selected.

Focus

The palette is a native dialog opened with showModal(), so the browser makes the rest of the page inert, traps Tab inside and handles Esc. When it closes, focus returns to the element that had it before.

Announcements

A polite live region says how many results there are, after a short pause so it does not speak on every keystroke. Commands that change something silently, such as copying the link, report through another live region.

Reduced motion

The open animation and the toast fade only run when the visitor has not asked for reduced motion. The flash on a heading you jump to is switched off the same way.

IME composition

While an input method is composing text (Japanese, Chinese, Korean), Enter confirms the composition and the arrow keys pick candidates. The palette ignores both until the composition ends, so confirming a word never opens a result by accident.

Touch screens

The header button opens the palette without a keyboard. On narrow screens the palette fills the viewport and rows are tall enough to tap. The keyboard hints are hidden on devices that cannot hover.
